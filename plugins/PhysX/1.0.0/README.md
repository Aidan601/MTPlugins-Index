# PhysX Placement

By SaintVertigo

PhysX Placement uses NVIDIA PhysX 3.4 for Radiant placement previews. Select up to 16 models, classic world brushes, or patches, then choose **Drop selected** in the PhysX pane. All selected objects fall in one shared scene and can collide with one another. Each placement is its own undo step. The objects fall into nearby map geometry; rigid bodies get their rotation from PhysX contact forces, and the results are written to the map when they settle. **Stop** freezes the current poses, **Place preview** commits them, and **Cancel** restores the original objects.

The rigid body for a classic brush is cooked from its brush faces. The Radiant host exposes model bounds rather than posed model meshes, so rigid model drops still use a box made from the model bounds. For cloth, character-like model bounds may use rounded head, torso, arm, and leg capsules; other bounds keep the bounds collider. This proxy is an approximation inferred from bounds, not the rendered model mesh. Model angles update live in the renderer during a rigid preview; cancel restores the original angles, and placement is saved as one undoable edit.

Enable **Simulate patches as cloth** to simulate a finer PhysX mesh sampled from the patch's quadratic Bezier control net. The mesh adapts to the control-net size; the two finest edge-detail settings allow up to 4,352 particles. By default, the settled surface is rebuilt as a denser patch so it follows the simulation more closely. **Keep original patch vertex count** is unchecked by default; turn it on to fit the cloth back into the original grid, which can smooth away small folds. Radiant's patch API and the plugin check the final grid for non-finite, out-of-range, or collapsed geometry before rebuilding it; an unsafe fold leaves the preview paused so it can be cancelled instead of crashing the editor. Resized cloth grids preserve the source material UVs across the new control net, so the texture stays attached to the cloth instead of accumulating per-edge UV changes across folds. The **Fold smoothing** setting also clamps isolated spikes. Cloth collides with nearby static map geometry, including brush hulls, model bounds, and neighboring patch surfaces. The source patch limit is 256 control points.

The pane has persistent settings for cloth detail, gravity, damping, and stretch stiffness. Cloth also uses PhysX self-collision so folds can contact other parts of the same patch; this reduces intersections but is not a guarantee against them. Trigger, volume, zone, and struct entities and brushes made entirely from hidden tool materials are ignored as colliders. Changes apply to the next drop. Higher detail preserves smaller folds but takes more simulation work. Cloth advances in short asynchronous steps so Stop and Cancel stay available while it moves; rigid objects use short synchronous steps and stop automatically once their motion stays low. The simulation catches up across slow editor frames, and the cloth solver uses a 240 Hz frequency to reduce lag.

Requires MTPlugins 1.0.0 or later, Radiant only. The PhysX CPU runtime DLLs and NVIDIA's license notice come with the plugin, so no PhysX install is needed.

This tool simulates up to 16 selected moving objects together against nearby static map geometry. Brush entities such as `func_*` are not supported yet.
